#+title: Vicmartos's Emacs Configuration
#+author: vicmartos

Emacs 31.1+ configuration, run as a ~systemd~ user daemon and accessed
through ~emacsclient~.

* Design goals

- Run Emacs in the background and open frames with ~emacsclient~.
- Standard Emacs editing by default, with Meow available on demand.
- Minimal GUI chrome: no menu bar, tool bar, scroll bars, or tooltips.
- Package management through ~use-package~ and MELPA.

* Starting the daemon

#+begin_src sh
  systemctl --user enable --now emacs
  systemctl --user status emacs
#+end_src

* Opening Emacs

In a terminal:

#+begin_src sh
  emacsclient -t
#+end_src

As a detached GUI frame:

#+begin_src sh
  nohup emacsclient -c -n < /dev/null > /dev/null 2>&1 &
#+end_src

* Installing or updating packages

Run standalone Emacs to install or update packages:

#+begin_src sh
  emacs -nw
#+end_src

Save your work, then restart the daemon:

#+begin_src sh
  systemctl --user restart emacs
#+end_src

* Workspaces

Terminal frames use a project-focused workflow without perspectives.  Running
~emacsclient -t~ (or ~e~) without file arguments opens Dired in the invoking
shell's directory; explicit file arguments open those files as usual.

| Key       | Terminal action                                      |
|-----------+------------------------------------------------------|
| ~C-x b~   | Switch buffers in the current project.                |
| ~C-x C-b~ | List buffers in the current project.                  |
| ~C-x B~   | Select any buffer using Consult.                      |
| ~C-x k~   | Kill a buffer normally.                               |
| ~C-x p f~ | Find a file in the current project.                    |
| ~C-x g~   | Open Magit status.                                    |

Outside a project, ~C-x b~ and ~C-x C-b~ show all buffers.  Terminal clients
share live buffers with the daemon, but do not restore or save workspace
layouts.  ~C-x g~ also works in GUI frames.

~persp-mode~ keeps workspaces in the daemon, shared across GUI client frames.
Closing a frame keeps its workspace and live buffers; a new frame resumes
the last workspace.  Each workspace has its own buffer list and window layout.

| Key           | Action                                             |
|---------------+----------------------------------------------------|
| ~C-x b~       | Switch between buffers in the current workspace.   |
| ~C-x B~       | Add an existing buffer; ~C-u~ also switches to it.   |
| ~C-x C-b~     | List the current workspace's buffers.               |
| ~C-x k~       | Kill or detach a buffer from the current workspace. |
| ~C-c p s~     | Switch to a workspace, or create one by name.        |
| ~C-c p n / p~ | Switch to the next / previous workspace.            |
| ~C-c p a~     | Add an existing buffer to this workspace.           |
| ~C-c p k~     | Remove a buffer from this workspace.                |
| ~C-c p K~     | Close this workspace and kill all its buffers.      |
| ~C-c p w / l~ | Save / load workspace state manually.               |
| ~C-c o o~     | Open the Org layout.                               |
| ~C-c o c~     | Open the configuration layout.                     |
| ~C-c o p~     | Open a project workspace.                          |
| ~C-c o a~     | Pick an agent and switch to its workspace.              |

Open ~ghostel-project~ with ~C-x p t~ and run ~codex~, Cursor's ~agent~,
or ~opencode~ normally.  Use ~C-u C-x p t~ for another terminal.  ~C-c o a~
searches agents across workspaces by app, status, directory, workspace, and
buffer name.  Shared agents prompt for a workspace; selection focuses the
terminal while preserving the workspace layout.  Terminal frames switch
buffers directly.

Discovery uses reported application identity or local foreground executable/
script identity, never buffer names.  Extend ~my/agent-identities~ for other
CLIs.  Interpreter wrappers with generic script names may not be recognized
unless the program reports its application identity.  Remote agents require
reported identity.  Working/done/blocked/error/idle states require status
reports understood by Ghostel; otherwise the picker says "status unavailable".
Status labels are colored blue for working, gray for idle, yellow for blocked,
red for errors, and green for done.  Customize the ~my/agent-*~ faces to change
these colors.
The list refreshes when opened, and completed records remain until Ghostel
clears them.  The custom Cursor/OpenCode project launchers have been removed.

The initial ~main~ workspace is a regular, filtered workspace.  Buffer
selection uses persp-mode's native completion, including the standard
~C-x 4 b~ and ~C-x 5 b~ commands for another window or frame.

~C-c p K~ also kills buffers shared with other workspaces.  Normal prompts
for unsaved changes and running processes still apply.  If a buffer is kept
or the command is cancelled, the workspace remains with its surviving buffers.

Workspace state is saved under ~persp-confs/~ when the last GUI client frame
closes and when Emacs exits.  After a daemon restart it restores shortly
after the first GUI client frame opens.  File buffers and layouts can be restored
from disk; running terminal and agent processes survive frame closure only
while the daemon remains running.

Workspace state from the old ~perspective~ package (~persp-state.el~) is
left intact and is not imported into the new format.
