#+title: Vicmaeg's Emacs Configuration
#+author: vicmaeg

Emacs 31.1+ configuration, run as a ~systemd~ user daemon and accessed
through ~emacsclient~.

* Design goals

- Run Emacs in the background and open frames with ~emacsclient~.
- Selection-first modal editing with Meow in terminal and GUI frames.
- Minimal GUI chrome: no menu bar, tool bar, scroll bars, or tooltips.
- Package management through ~use-package~ and MELPA.

* Starting the daemon

#+begin_src sh
  systemctl --user enable --now emacs
  systemctl --user status emacs
#+end_src

* Opening Emacs

In a terminal:

#+begin_src sh
  emacsclient -t
#+end_src

As a detached GUI frame:

#+begin_src sh
  nohup emacsclient -c -n < /dev/null > /dev/null 2>&1 &
#+end_src

* Installing or updating packages

Run standalone Emacs to install or update packages:

#+begin_src sh
  emacs -nw
#+end_src

Save your work, then restart the daemon:

#+begin_src sh
  systemctl --user restart emacs
#+end_src
